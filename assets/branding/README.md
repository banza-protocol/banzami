# Banzami Brand Assets

Source brand images for the Banzami operator. These are reference/source assets — apps keep their own platform-specific copies under `apps/*/assets/` and `apps/*/public/`.

## Files

```
assets/
  icons/
    banzami_icon.png      ← app icon (1254×1254, red rounded-square mark)
  branding/
    banzami_logo.png      ← logo (1254×1254)
    banzami_splash.png    ← splash image (1254×1254)
```

## Derivation Guide

| Platform | Size | Source |
|----------|------|--------|
| iOS App Store | 1024×1024 | `icons/banzami_icon.png` |
| Android Play Store | 512×512 | `icons/banzami_icon.png` |
| Favicon (browser) | 32×32, 64×64 | `icons/banzami_icon.png` |
| Apple Touch Icon | 180×180 | `icons/banzami_icon.png` |

> Replaced 2026-06-13: the previous brand images in `assets/` were not the Banzami brand and were removed; these three are the canonical Banzami brand source (red rounded-square mark).
